PIXELCAKE · CONCEPT Ⅱ · 2026-10

「Aperture 光圈」—— 一个表面的修图台

这一版不再有「面板」这个概念。照片永远是唯一的主角，所有控制压缩成底部两条固定的带子： 工具栏（选工具）+ 控制台（这个工具的旋钮）。 调参有两种通道——直接在照片上拖（快、凭感觉），或在控制台拖滑块（慢、要精确）——两者改的是同一个参数。 作用域不再靠文字 chip 猜，而是点哪修哪：点一下照片里的人，蒙版就圈住他。

01一个表面 One-Surface 从进入到导出，编辑器只有一屏。工具切换 = 底部两条带子的内容变形，布局永不重排。 数据层已支持

03双通道调节 Dual-Input 照片上横拖 = 调参（Snapseed 式），上下滑 = 换参数；控制台滑块永远同步。手指不离照片完成 80% 的调整。 手势机已有 · 需扩展
04强度即语言 Amount 任何预设套上后只暴露一个「强度」环——参数栈整体向中性插值。风格的深浅由一个旋钮决定。 引擎小改：参数栈 lerp

02

设计语言 · 暗房与安全灯

隐喻只有一个：暗房。世界是暖石墨，唯一的光是琥珀色的安全灯——它只照亮「你正在动的东西」。强调色不再是装饰，而是注意力的路由器。

中性阶整体偏暖（黄相 +2），与肤色、木、胶片同一温度。琥珀只允许出现在四处：选中态、拖动中的填充与拇指、蒙版轮廓、主 CTA——出现在别处即违规。

首页成片卡的紫黑→琥珀金四色渐变（§04-A，实现侧 token `HeroCardTop…Bottom`） 是「照片占位」语义——讲「底片 → 出片」的叙事，属于内容占位而非品牌色板； 品牌面仍只有石墨与琥珀（与 §2.5 图标「不做大面积彩渐变」不冲突：那条约束的是图标本体）。

2.2 自适应材质（本版独有）直方图均值已算好

控制台与顶栏的明暗跟随照片：渲染管线已经在算直方图，取其均值—— 均值 < 0.35 → 暖石墨控制台；均值 > 0.65 → 纸色控制台（琥珀同步切深档 #B8791A 保对比度）。 效果是「界面永远衬得出生体照片」，雪景不会白成一片、夜景不会黑成一团。切换只动表面色与文字色，布局零变化。

06

性能与字号审计 · 流畅易用的硬指标

设计稿不是画完就算——这一节把「流畅」和「易读」翻译成可验收的数字。标 ✓ 的项已按审计结果回改了本稿（不是停在纸面）。

6.1 字阶使用规则（五档不变，补三条红线）

规则内容状态
可点击文字 ≥ 11sp按钮 / 工具栏 / Tab / 入口胶囊的文字标签下限 11sp；且 12sp 以下不得作为唯一编码（必须伴随图标或颜色）✓ 工具栏、底部 Tab、首页入口胶囊 10 → 11sp
状态徽章 ≥ 10.5spbadge 是「状态确认」信息（有颜色 + 图标伴随），可低于交互文本但不得低于 10.5sp✓ badge 10 → 10.5sp
辅助信息分级非关键信息（时间戳 / 参数名 / 路径详情）允许 10sp，且必须配 Ink-3 弱色；操作说明等关键文字一律 ≥11sp✓ 参数格标签 9.5 → 10sp
系统字体缩放fontScale 1.0–1.3 全量适配（sp 布局自然放大，布局不裁切）；控制台 L 档高度随缩放放宽（330→356dp）；≥1.3 时设置页提供独立「放大文本」开关新增
数值稳定一切数值 tabular-nums；deck 行内「标签左 / 数值右」互不换行（nowrap + 权重分配）沿用

对比度已核：Ink-2(#A5A29A) 于 Deck(#20201E) ≈ 7.4:1（安全）；Ink-3(#6B6963) ≈ 4.6:1——只允许承载非关键信息，禁止用它写操作说明。琥珀(#FFB454) 于 Deck ≈ 9.8:1，选中态文字无障碍达标。

6.2 帧预算与内存预算（120Hz = 每帧 8.3ms）

预算项上限落点 / 纪律
UI 线程每帧组合 <3ms · 布局 <2ms · 绘制 <3ms像素渲染全部在后台分带线程完成；UI 线程只组合「已有位图」，不做任何逐像素工作
常驻合成层编辑器 ≤ 4 层照片 / 控制台 / 工具栏 / 顶栏。backdrop-blur 只允许顶栏与把手段；控制台用实心 94% α（零 blur）——满屏玻璃是掉帧第一来源
拖动期重组0 次布局变化隐形式只动 alpha；缩放 / 平移走 graphicsLayer（组合外读值，offset/graphicsLayer 用 lambda 版）；全部状态读取 lambda 化防陈旧捕获
位图常驻（UI 侧）峰值 ≤ 55MB代理预览 11MB + 渲染双缓冲 22MB（峰值）+ 分割概率 1.5MB + 蒙版网格 ≤2MB + 两模型 17MB；导出走全分辨率分带渲染，不进堆
动画属性白名单只允许 transform / opacity / 颜色pressScale（graphicsLayer）、扫光（drawWithContent）、材质切换（animateColor）——任何触发重排的动画都不许上

手势跟手性按下到首帧位移反馈 <1 帧touchSlop 8dp；双击窗口 280ms；滑块拖动中禁用任何非值动画写入

6.3 横屏适配规则（可用宽 ≥600dp 即启用）

屏横屏形态
系留仪表盘（J′）左预览 + 右 252dp 参数栏；预览最小高度 = 屏高 − 24dp——横屏下照片是全 App 最大的时刻，分割对比默认展开
会话批量（L′）网格 2 列 → 4 列，底部操作条不变
拍摄流（K）全宽预览 + 底部横向时间线（同一批组件重排）
编辑器控制台右移成侧栏（复用 deck 内容），照片拿左侧全部空间；手势与缩放状态机与方向无关，零改动

所有横屏布局不引入新组件、不引入新状态——只是同一批组件的重排，这是横竖屏不打架的唯一保证（J′ / L′ 两屏即证）。

07

手势地图 · 优先级从高到低

冲突裁决只有一条：放大之后，单指永远属于「移动照片」，手势调参自动让位。

手势行为条件 / 说明
照片上横拖调当前参数（巨大 HUD 回显）缩放 = 1x 时；控制台滑块同步
照片上竖滑组内切换参数 / 跨组切换上滑下一个参数，到组尾跳下一组
轻触照片（拾取模式）命中分割蒙版 → 选中作用域作用域按钮进入拾取；非拾取时轻触 = 无操作
双指捏合 / 拖动缩放（≤8x）+ 平移任何模式下可用；放大后单指 = 平移
双击2.5x ↔ 1x（以点击处为锚）与 v2.1 已实现行为一致
长按照片看原图（松手还原）仅 1x；顶栏 ⇔ 为分割对比
控制台滑块精确调节 + 长按数值微调与手势通道实时同步
08

两版怎么选 ·「Studio」vs「Aperture」

两版是同一个产品的两种性格，可以整版二选一，也可以按行混搭（每行都标注了混搭的代价）。

维度「Studio」（UI2.0.html）「Aperture」（本稿）
结构全屏画布 + 三档浮动 Sheet（面板可展开遮住大半屏）一表面 + 固定高控制台（任何时刻最多 330dp，永远看得见照片）
调参主通道滑块优先，手势为辅手势优先（照片即滑块），滑块为精密档
作用域文字 chips（整图/人物/皮肤…）点哪修哪（蒙版命中 + 轮廓可视化），chips 兜底
预设2 列网格全开档2×2 卡 + 强度环（参数栈 lerp）
对比长按看原图长按 + 分割线对比
材质深色固定 + 玻璃浮层自适应（暗照片→石墨，亮照片→纸）+ 玻璃仅顶栏
强调色珊瑚（人像亲和）琥珀（暗房安全灯，注意力路由）
直方图明暗面板内顶部常驻条（全工具可用，可收起）
适合谁习惯「打开面板慢慢调」的 Lightroom 用户习惯「在照片上直接操作」的 Snapseed / 手势党；单手场景压倒性优势

可行性总结与落地顺序

好消息：本稿最贵的两样东西——分割蒙版与手势状态机——引擎里都已经存在，缺的只是接线和两处小改。

概念工程状态依据
One-Surface（rail + deck）数据已支持每组控件本来就是「chips + 滑块」结构，deck 是它的固定高呈现
双通道调节（照片上拖）手势机扩展v2.1 已落单协程手势状态机（含缩放仲裁），加「横拖调参/竖滑换参」两个分支
点哪修哪交互新接线6 类 FloatGrid 蒙版已缓存（ObjectMasks），命中 = 采样一个像素的概率比较
强度环引擎小改参数栈整体向中性 lerp（纯数学）；retouch 强度同乘
自适应材质小改直方图均值已在算（§04 明暗页），加两档 token 切换
分割对比 / 历史丝带（文字版）/ 导出回执数据已支持rendered + compareBase 双位图；EditSnapshot 栈；Exporter 返回 uri
系留出片（连接 → 拍摄 → 自动套预设 → 出片 → 批量）链路已支持PTP 下载（CameraSession）+ 单张套预设处理（CameraBatch）都已存在；缺「会话内新对象轮询 + 默认预设接线」
相机参数面板（电量 / 存储 / 曝光参数）协议小改GetStorageInfo 已接；电量与曝光参数需 GetDevicePropValue 扩展（PTP 帧已有）

横屏双栏（系留仪表盘 / 批量 / 编辑器侧栏）纯布局同一批组件重排（J′ / L′ 即证）；手势与缩放状态机与方向无关，零改动
自动增强待引擎需新算子（分析 + 参数推荐），入口已留
首页「最近编辑」需持久化需保存编辑会话记录（P4 预设库同批）

色板 / 字阶 / 图标集 / 巨大 HUD / 强度环 / 历史丝带（文字版）。纯增量，零布局风险。
