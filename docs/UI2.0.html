PIXELCAKE · DESIGN SPEC · 2026-10

UI 3.0 「Studio」

照片占满整块屏幕，控件按需浮出，拖动时只留一个读数。 从 Lightroom 取「仪器式的秩序」，从 Snapseed 取「隐形式的专注」， 从美图秀秀取「触达的友好」，从像素蛋糕取「人像的专业」—— 四者收敛成一句话：让用户忘掉界面，只看见照片。

01照片即界面全屏画布取代分屏：照片永远最大，面板是浮在上面的临时层，不是与照片分蛋糕的对手。
02秩序消化复杂度图标 + 文字的底部 dock、三档收放的参数 sheet、永在视野的中央读数——81 项参数各有其位。
03触手可及全部高频控件落在拇指热区（屏高下 60%）；48dp 起步的命中面积；单手完成「选工具 → 调参 → 导出」。
01

从四个对标里各取什么

抄思路，不抄外观。每个来源只取被其用户验证过的一个强项，落点全部对应本文的具体组件。

来源提取的优点在 3.0 的落点
Lightroom Mobile仪器式的秩序：全屏照片 + 悬浮面板；图标化导航；拖动时参数名与精确数值永远可见；直方图常驻§4-B/C 全屏画布与浮动 sheet · §4 底部 dock · 中央 HUD 读数（§4-D）· 明暗页直方图（§4-C）
Snapseed隐形式的专注：调参时界面完全退场，只剩照片与一个参数胶囊；手势优先于按钮拖动时全部 chrome 淡出 + 中央 HUD（§4-D）· 双击缩放 / 长按对比 / 双指平移的手势体系（§5）
美图秀秀触达友好：图标 + 文字的双重编码；预设以大卡片呈现，一眼可扫；「一键增强」降低上手门槛dock 每项带文字标签 · 预设 2 列大卡网格（§4-F）· 「自动增强」入口（预留，待引擎接线）
像素蛋糕（桌面版）人像的专业分工：肤色 / 面部 / 形体分区明确；作用域（蒙版）可视化；批量出片人像面板的作用域 chips + 画布工具（§4-E）· 相机批量链路维持现状

05

手势速查

全屏画布把手势从「加分项」变成「主干」。规则只有一套，三种画布工具下永不变形。

双指捏合 / 拖动

缩放（≤8x）+ 平移。三种工具下行为一致——编辑时也要能放大精修。

双击

2.5x ↔ 1x 切换，以点击处为锚（点住的内容不动）。

单指拖动（已放大）

查看 / 祛瑕模式 = 平移；画笔模式永远是涂抹——精修时手指不能突然从「画」变成「挪图」。

长按照片

按住看原图（同管线零编辑基准），松手还原。

上滑 / 下拉 sheet

收起 ↔ 半开 ↔ 全开三档切换；面板开合不影响已放大的照片尺寸。

拖动滑块

全部 chrome 淡出，中央 HUD 显示参数与数值；长按数值 = ±0.05 微调。

06

v2.1 → 3.0 变更对照

六处结构变化 + 两处 token 变化；其余（字阶 / 间距 / 圆角 / 动效分族 / 无障碍逃生舱）全部延续。

项v2.1（现状）3.0
编辑页结构分屏：预览 45% / 参数 55%，中间分隔条全屏画布 + 三档浮动 sheet。消灭「面板与放大照片抢空间」「矮屏预览成缝」两类结构病
一级导航纯文字玻璃分段条图标 + 文字 dock（识别更快，专业观感；分类 6 个不变）
调参反馈滑块旁数值 + chrome 淡出中央 HUD（参数名 + 精确读数浮在照片上），chrome 全退场
预设浏览横向滚动单行缩略图2 列大卡网格（sheet 全开档），一屏可扫 6 套
直方图仅在明暗页顶部维持明暗页；形态统一为三通道叠加组件（可复用到曲线页）
新入口—「自动增强」预留位（顶栏 wand，待引擎接线后启用）
强调色紫罗兰 #A894FF（暗）珊瑚 #FF8B6A / #E4694B（与肤色同域、去 AI 冷感；紫保留为备选，改一行 token 可切回）
玻璃范围TabBar / 分段条 / 卡片默认实心进一步收敛：只允许 chrome 浮层（顶栏 / dock / HUD / 胶囊 / 把手段），面板主体实心
07

落地顺序建议

每阶段独立可发版、可回退；全程遵守「引入新文件先过本地静态闸门、每轮 CI 后覆盖重写 Github_CI.md」。

P1
Token 与组件层（低风险）

accent 珊瑚切换 + 图标集（vector drawable）+ HUD 组件 + 直方图组件 + dock 控件。纯增量，不动布局。

P2
画布化（结构改造）

EditorScreen 由分屏改全屏画布 + sheet 三档；分隔条退役（保留 zoom 补偿逻辑的等价物：sheet 开合不改照片显示尺寸）。手势体系复用 v2.1 已落地的状态机。

P3
面板内容迁移

六分类面板搬进 sheet（结构不变）；预设改网格；导出 sheet 按 §4-H 重排。撤销 / 作用域 / 撤销栈逻辑零改动。

P4
收尾

首页浅色微调对齐新 token；「自动增强」待引擎侧（highlightRecovery + 预设 auto 栈）接线后启用；真机验收清单见 Github_CI.md 待办区。

风险与对策：① sheet 盖住照片后的渲染位图仍按屏幕长边定尺，内存不变；② 隐形式交互复用 dragging 状态机（含 onDispose 兜底，见 ENGINEERING_NOTES §8.2-5）；③ dock 图标必须同族线性 1.5px 圆头，禁混 Material 填充图标。
